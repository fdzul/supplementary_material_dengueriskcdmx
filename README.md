# Supplementary material: Risk Map of Dengue Transmission in the Metropolitan Area of Mexico City

Extended methods and supplementary results for the manuscript *Risk Map of Dengue Transmission in the Metropolitan Area of Mexico City*:

- **Part A.** Extended methods.
- **Part B.** Results of the *Aedes aegypti* (ovitrap) model.
- **Part C.** Results of the imported dengue cases model.
- **Part D.** Results of the risk map.

## Files

- `supplementary_material.html`: rendered document (self-contained; open in a web browser).
- `supplementary_material.qmd`: Quarto source.
- `fig_1_study_area.jpg`, `esquema_experimentos_en.png`, `reduccion_datos_en.png`: images used by the document.

## Related software

R package [`dengueriskcdmx`](https://github.com/fdzul/dengueriskcdmx): *Ae. aegypti* data, probability rasters and risk map, and the code of the workflow.

## Data availability

Confirmed dengue case data are not distributed.
